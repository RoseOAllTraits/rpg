# The Quiet Within: Offline Play

The game includes 60 chapters of 50 playable levels, using local deterministic narrative arcs. The original 15 authored scenes are preserved. No AI service, account, remote image, or remote font is required.

## Installed Browser Copy

Open the site online once and wait until Reading & settings > Offline play confirms that all files are cached. On iPhone and iPad, use Share > Add to Home Screen, open that copy, and let it finish its first download. On Android or desktop, use your browser's install option if available. Test opening the installed copy in airplane mode before travel. Browser caches and saves can still be removed by the device, private browsing, or clearing site data. Export a journey as a separate backup.

## Extracted Folder on a PC

Extract the entire ZIP, then open index.html in a current browser. Do not open the HTML while it is still inside the archive. Keep all files and folders together. The game uses ordinary scripts and works without a web server. File-URL save storage varies by browser and folder location: export your save before moving the folder. If a browser blocks local-file storage, use Export current journey before closing.

Mobile file managers do not reliably launch multi-file websites. Use the installed browser copy on mobile, not a single HTML file opened in a file preview.

## Saves and Speech

Saves use local storage and an IndexedDB device backup when permitted. Saves are not shared between browsers, profiles, the extracted folder, and the installed copy. Use Saves & files to export and load .quiet.json files. Import supports files up to 10 MB.

Read-aloud uses on-device speech voices only. A suitable voice must already be installed. If no local voice is available, the story and meditations still work but read-aloud cannot speak.

## Content

Levels 16-3000 are expanded deterministically from 300 chapter-specific situations with shared narrative beats. They are playable offline with persistent choices and conditional follow-ups, but are not 2,985 individually hand-written scenes. Regions are visited in order.
